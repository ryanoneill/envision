# ratatui 0.30 Upgrade Implementation Plan — Part 1: header and green pre-bump tasks

> This plan is split across three files to respect the 1000-line limit: Part 1 (this file: header, constraints, Tasks 0–4), [Part 2](2026-10-10-ratatui-0.30-upgrade-part2.md) (Task 5), [Part 3](2026-10-10-ratatui-0.30-upgrade-part3.md) (Tasks 6–11).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move envision from ratatui 0.29 / crossterm 0.28 to ratatui 0.30.2 / crossterm 0.29 (PR 3 of the security programme), removing RUSTSEC-2024-0436, RUSTSEC-2026-0002 and RUSTSEC-2026-0253 from envision's tree.

**Architecture:** First, green commits on 0.29 for every change that does not need 0.30: `#[non_exhaustive]` and `From<Infallible>` on `EnvisionError`, re-exports, private `EnhancedCell` fields, and characterization tests. Then failing tests for the bump. Then the bump itself: honest backend error types with method-level `EnvisionError: From<B::Error>` bounds, a `SerializableDiffOption` mirror with lossless legacy JSON, one control-byte-safe width helper, and terminal wide-glyph emulation in `CaptureBackend`. Last, a snapshot-only commit backed by a four-part proof, then docs.

**Tech Stack:** Rust 2024 (MSRV 1.88), ratatui 0.30.2 (ratatui-core 0.1.2, ratatui-widgets 0.3.2, ratatui-crossterm 0.1.2), crossterm 0.29, serde, insta, trybuild, cargo-nextest, cargo-audit, cargo-deny.

**Spec:** `docs/superpowers/specs/2026-10-09-ratatui-0.30-upgrade-design.md`, approved by all reviewers at `69e972f`. Read it alongside this plan. Section references below (§ N) point into it.

## Global Constraints

- **Preconditions.** PR 1 (`Cargo.lock` refresh) and PR 2 (MSRV 1.88 + 81 clippy fixes + `msrv` CI matrix) have merged to `main`. This branch starts from that `main`.
- **ratatui:** `ratatui = { version = "0.30.2", default-features = false, features = ["crossterm_0_29", "underline-color", "layout-cache"] }`.
- **crossterm:** `crossterm = { version = "0.29", features = ["event-stream"] }`.
- **serde:** `serialization` keeps `"ratatui/serde"`.
- **No unsafe.** No `unwrap`/`expect` on `Infallible` results in library code — use `let Ok(x) = …;`.
- **Warnings:** none. The only allowance is one scoped `#[allow(deprecated)]`, in the function that reads ratatui's deprecated `Cell::skip`.
- **File size:** no file over 1000 lines. Watch `src/app/runtime/builder.rs` (944), `src/app/runtime/mod.rs` (875) and `src/backend/capture/mod.rs` (710).
- **Commits:**
  - every commit is signed (`git commit -S`), runs `cargo fmt --all` first, and ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - **do not push** until the snapshot-only commit (Task 9) exists;
  - the PR is squash-merged.
- **Widths:** every width in envision code comes from the crate-internal helper `crate::backend::cell::width::symbol_cell_width`. Never call `CellWidth::cell_width` or `Cell::cell_width` directly.
- **Error bound:** `EnvisionError: From<B::Error>`, as a method-level `where` clause on exactly the methods listed in Task 6, never on an impl block or a struct.
- **trybuild tests:** every one carries `#[cfg_attr(tarpaulin, ignore = "trybuild invokes cargo; not meaningful under coverage instrumentation")]` (convention from #523; `CONTRIBUTING.md` § Coverage), so the Coverage job does not rebuild the dependency tree under instrumentation.
- **JSON wire format:** `SerializableDiffOption` is `snake_case`. `EnhancedCell` JSON never writes `skip`, and writes `diff_option` only when it is not `none`.

## Review Focus

Five conditions the spec implies that no task's own tests would otherwise exercise, most likely first. Each has a test added to its owning task (marked **[RF-n]**).

1. **RF-1: `clear()` / `clear_region()` after a wide glyph.** A later narrow write into a former continuation column must not blank anything, because no owner remains. *Task 8.*
2. **RF-2: history and diff.** `with_history` snapshots and `diff_from_previous()` count cells blanked by wide-glyph emulation as changed in that frame. *Task 8.*
3. **RF-3: precedence.** JSON with both `"skip": true` and `"diff_option": "always_update"` loads as `AlwaysUpdate`, following upstream's rule that `skip` is honoured only with `None`. *Task 7.*
4. **RF-4: `DualBackend<CaptureBackend>` as a Runtime backend.** Both halves are `Infallible`; it builds, renders and ticks. *Task 6.*
5. **RF-5: a wide glyph partly off the row end** (`ForcedWidth(5)` at column `width-2`) blanks only in-row cells and never panics. *Task 8.*
