### Task 2: Fix frozen criterion baselines in CI

**Files:**
- Modify: `.github/workflows/ci.yml`, the bench jobs `bench-backend` (~283-330), `bench-runtime` (~333-380), `bench-component-view` (~383-430), `bench-component-events` (~433-480) and any further `criterion-baseline-*` jobs (`grep -n criterion-baseline .github/workflows/ci.yml`).

**Current shape, per job:**
- the restore step is `actions/cache@v4`, with `key: criterion-baseline-<b>-${{ github.base_ref || 'main' }}` and `restore-keys: criterion-baseline-<b>-main`;
- the save step is `actions/cache/save@v4`, with `key: criterion-baseline-<b>-main`, on main pushes only.

Caches are immutable, and an exact key match beats `restore-keys`, so the baseline never updates.

- [ ] **Step 1: Rewrite each job's restore step**

```yaml
      - name: Restore baseline
        uses: actions/cache/restore@v4
        with:
          path: target/criterion
          key: criterion-baseline-<b>-main-${{ github.run_id }}
          restore-keys: |
            criterion-baseline-<b>-main-
```

Keep the existing `path:` value exactly as it is today. Substitute `<b>` with the job's existing name (`backend`, `runtime`, `component-view`, `component-events`, …).

- [ ] **Step 2: Rewrite each job's save step**

```yaml
      - name: Save baseline
        if: github.ref == 'refs/heads/main' && github.event_name == 'push'
        uses: actions/cache/save@v4
        with:
          path: target/criterion
          key: criterion-baseline-<b>-main-${{ github.run_id }}
```

Keep the existing `if:` condition, extended only if it lacked the push check. Keep `path:` identical to the restore step.

- [ ] **Step 3: Validate the workflow**

```bash
python3 -I -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))" && echo yaml-ok
grep -n "criterion-baseline" .github/workflows/ci.yml
```

Expected: every key ends `-main-${{ github.run_id }}` or `-main-`, with no unsuffixed `-main` key left. If `actionlint` is installed, run it.

- [ ] **Step 4: Commit**

```bash
git add .github/workflows/ci.yml
git commit -S -m "CI: criterion baselines keyed by run_id with prefix restore

Actions caches are immutable and an exact primary-key match beats
restore-keys, so the fixed criterion-baseline-<bench>-main key froze
baselines at the first-ever save. Save under -main-<run_id> on main
pushes; restore the newest via the trailing-dash prefix.

Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>"
```
